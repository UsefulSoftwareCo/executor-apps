# Simpplr

Covers Simpplr's B2B API for managing an intranet: sites and site membership, pages, events, albums, page categories, content approval and publishing, bulk content operations, feeds, comments and reactions, audiences and their members, tasks and task fields, people attributes, files and signed uploads, and analytics exports. 53 tools in all (36 mutations, each requiring approval).

Interface: OpenAPI 3.0, Simpplr's official B2B API definition from https://platform.simpplr.com/reference. The developer hub is a ReadMe site that serves each operation page with its own slice of the definition and offers no downloadable file, so `document.json` is those 50 slices merged (nested JSON-pointer references hoisted into `components/schemas`). The document's server and token URL point at placeholder hosts (`platform.{env}.simpplr.xyz`); each account instead uses its own regional host `https://platform.<region>.simpplr.com`, and credentials are only ever sent there.

Auth: one method, client application credentials (OAuth 2.0 client credentials grant). Create a client application as described at https://platform.simpplr.com/reference/creating-the-client-application and copy its Client ID and secret. When connecting, enter your tenant's region (`app` for the United States, or `eu`, `au`, `ca`), the Client ID and the secret. Executor requests a token with scope `everything` at `https://platform.<region>.simpplr.com/v1/identity/oauth/token` and renews it as it expires. The grant is performed in code rather than with the framework's `oauth2` method because the token URL depends on the region. There is no browser redirect.

Known gaps: Simpplr's separate User API (authorization-code flow, acting as an individual user) is not included. The B2B definition does not list every endpoint (for example the connection test `GET /v1/b2b/identity/test`, which is only used for the health check). Tenants still running as a Salesforce managed package should use the Salesforce app. The icon is Simpplr's official site icon (512px PNG), since no SVG mark is published.
