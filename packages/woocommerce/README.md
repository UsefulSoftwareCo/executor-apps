# WooCommerce

Manage a WooCommerce store: products and variations, categories, tags, attributes and terms, reviews, orders with notes and refunds, customers, coupons, shipping zones (locations and methods), tax rates and classes, payment gateways, webhooks, settings, legacy reports, system status and reference data. Every list tool takes `query` filters (`page`, `per_page`, `search`, ...) and every write tool takes a JSON `body` following the REST API reference; resources with batch support also expose a `batch` tool.

**Interface:** hand-written tools over WooCommerce's official REST API v3 (`https://<store>/wp-json/wc/v3`, reference at https://woocommerce.github.io/woocommerce-rest-api-docs/). WooCommerce publishes no OpenAPI document. Its official MCP integration (`/wp-json/mcp/mcp-adapter-default-server`, https://developer.woocommerce.com/docs/features/mcp/) is a developer preview, off by default, needs the WordPress MCP Adapter plugin and a WordPress application password, and only exposes product and order abilities, so it is not used. The older `/wp-json/woocommerce/mcp` endpoint is deprecated. All mutations require approval.

**Auth:** REST API keys. In wp-admin open WooCommerce > Settings > Advanced > REST API > Add key, pick a user and Read, Write or Read/Write permissions, and copy the consumer key (`ck_...`) and consumer secret (`cs_...`). Enter your store URL (https; sub-directory installs keep their path) with the key pair; they are sent as HTTP Basic credentials, which WooCommerce accepts only over https. WooCommerce has no OAuth app registration for users (the legacy `/wc-auth/v1/authorize` flow only returns keys), so OAuth is not offered. The connection check calls `GET /system_status/tools`, which needs a key with Read access and an administrator-level user.

**Gaps:** stores are arbitrary hosts, so the provider declares no static `hosts` and the secret is not host-restricted by the framework (same decision as the other self-hosted packages: btcpayserver, gitea, metabase). Requests are always built from the account's store URL and only https is accepted. Not wrapped: the Store API (storefront cart and checkout), the experimental GraphQL API, the newer analytics endpoints (`/wc-analytics`), order and product CSV import/export, and subscriptions/bookings from extensions.
