# Rippling

Rippling's workforce platform through the v2 REST API: workers, users, compensation, job assignments, departments, teams, titles, levels, work locations, legal entities, leave requests and balances, time entries and cards, schedules and shifts, headcount, job requisitions and listings, custom fields and object categories, draft hires and a handful of write operations.

**Interface:** hand-written tools over the official Rippling v2 REST API (`https://rest.ripplingapis.com`, docs at https://developer.rippling.com/documentation/rest-api). Rippling publishes no downloadable OpenAPI document, no GraphQL API and no remote MCP usable with an API token (the first-party Rippling MCP acts as an individual employee and needs a Rippling AI subscription; the SDK MCP is a local stdio server). The endpoint list was taken from the paths of Rippling's official TypeScript SDK (`@rippling/rippling-sdk`) and checked against the docs index; 124 read tools and 20 write tools. Every tool takes its path ids, `query` (`limit`, `cursor`, `filter`, `expand`, `order_by`, see https://developer.rippling.com/documentation/rest-api/essentials/query-parameters) and, for writes, a JSON `body` following the API reference. Lists are cursor paginated. No `Rippling-Api-Version` header is sent, so the account's default version applies. All writes require approval.

**Auth:** API token. In Rippling open Tools, Developer, API Tokens and create a token (https://developer.rippling.com/documentation/rest-api/essentials/api-tokens). It is sent as a bearer token to `rest.ripplingapis.com`, and what it can do is the intersection of its scopes and the creating user's permission profile; a `null` field often means the token cannot see it. OAuth is not offered: Rippling OAuth is only for App Shop partner apps, uses a per-app authorize URL and client credentials issued after partner onboarding.

**Known gaps:** developer-portal and app-packaging endpoints (custom apps, pages, settings, sandboxes, package installs, sites, software deployments), file upload presigning flows beyond the plain files endpoint, and legacy V1 (`api.rippling.com`) APIs are not wrapped. Request and response bodies are free-form JSON rather than typed.
