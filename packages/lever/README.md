# Lever

Applicant tracking with Lever: opportunities (with stage moves, archiving, tags, links, sources, files, forms), contacts, notes, interviews, panels, feedback and feedback templates, offers, postings (including applying to one), requisitions and requisition fields, stages, archive reasons, sources, tags, profile form templates, users, webhooks, audit events and EEO responses.

**Interface:** hand-written tools over the official Lever Data API (`https://api.lever.co/v1`, reference at https://hire.lever.co/developer/documentation). Lever publishes no OpenAPI document and no official MCP server, and no official GraphQL API exists; only third-party specs (API Evangelist) are available, and they are not used. Each tool takes path ids, `query` for filters and, for writes, a JSON `body` following the reference. Lists page with the `offset` token returned as `next`. All writes require approval.

**Auth:**
- API key: in Lever open Settings, Integrations and API, API Credentials tab, and generate a key (https://hire.lever.co/developer/documentation#authentication). It is sent as HTTP Basic (key as username, blank password) to `api.lever.co`. Access to confidential data can only be granted when the key is created.
- OAuth 2.0: Lever OAuth apps are part of its partner program, so the app must be registered with Lever (https://hire.lever.co/developer/oauth), which issues a client id and secret. Register the Executor redirect URI shown on the connect page exactly. Authorization goes to `auth.lever.co` with audience `https://api.lever.co/v1/`; 20 scopes are requested (Lever's maximum): `offline_access`, `write:admin` for contact, feedback, interviews, notes, opportunities, panels, postings, requisitions, users and webhooks, and `read:admin` for applications, archive_reasons, files, forms, offers, resumes, sources, stages and tags (names from the Scopes list in Lever's documentation; write includes read). Token exchange posts client_id and client_secret in the form body. EU customers are redirected by Lever automatically; no EU host is documented, so none is configured. Feedback and form template, requisition field, referral, audit event and EEO tools need extra scopes and will return 403 under OAuth unless the app is registered with them; they work with an API key. Access tokens last one hour. The sandbox uses `sandbox-lever.auth0.com` and `api.sandbox.lever.co`, which are not configured here.

**Known gaps:** tools cover the documented Opportunities, Postings, Interviews, Feedback, Notes, Requisitions and administrative endpoints. Not wrapped: file uploads and file or resume downloads (binary), offer file downloads, referrals lookups by id, diversity surveys, the deprecated `/candidates` endpoints. Confidential opportunities need `confidential:access:admin`. The icon is Lever's wordmark, because Lever publishes no separate symbol.
