# OpenRouter

Unified LLM gateway: chat completions, responses, messages, embeddings, images, rerank, models and endpoints, generations, credits, API keys, guardrails, analytics/activity, BYOK, workspaces, organization, SCIM, end users, presets and more.

- Interface: OpenAPI, from OpenRouter's official document at https://openrouter.ai/openapi.json (live, not pinned). The spec declares 151 operations; 144 are generated under `api`. The 7 that declare a `text/event-stream` response are dropped by the framework (it does not list them as skipped, so `scripts/tools.ts` reports 0 skipped): `POST /chat/completions`, `POST /responses`, `POST /messages`, `POST /embeddings`, `POST /images`, `POST /rerank`, `POST /interns/{internId}/chat/completions`.
- Hand-written tools: six of those are re-added under `inference` as non-streaming JSON calls (`chatCompletions`, `responses`, `messages`, `embeddings`, `images`, `rerank`; `stream: false` is forced where the route has it). Each takes the main required fields plus a `params` object for any other documented body field. `POST /interns/{internId}/chat/completions` requires `stream: true`, so it is streaming-only and not exposed. Total: 150 of 151 operations reachable.
- Auth: API key (bearer token), for inference routes. Create a regular key at https://openrouter.ai/keys. Account administration (API keys, guardrails, analytics/activity, credits, BYOK, workspaces, organization, SCIM, end users and similar) needs a management key, created at https://openrouter.ai/settings/management-keys. Management keys cannot call completion endpoints and regular keys cannot call management routes, so connect one account per key type.
- Health check: `GET /api/v1/key`. Its documented response includes `is_management_key`, so it describes management keys too, but this was not exercised against a live key; if an account holding only a management key fails to connect, use a regular key.
- OAuth is not offered. OpenRouter's flow is a PKCE exchange (https://openrouter.ai/auth, then `POST /api/v1/auth/keys` returning `{ key }`) that yields a plain API key rather than an OAuth token set, so the framework's `oauth2` does not express it.- Gaps: no SSE streaming responses.
