# Acumatica

Acumatica cloud ERP. This package covers the contract-based REST API: customers, vendors, contacts, leads, opportunities, cases, employees, stock and non-stock items, sales orders and invoices, shipments, purchase orders and receipts, bills, payments, checks, journal transactions, GL accounts, projects and tasks, expenses and warehouses (list, get, create or update, delete for each), plus generic `entity.*` tools for any entity (including customized ones), `action` to invoke entity actions (for example ReleaseInvoice), `inquiry` to read generic inquiries exposed through OData, and `endpoints`/`schema` to discover what the instance serves.

**Interface:** hand-written tools over Acumatica's contract-based REST API (vendor docs: https://help.acumatica.com, "Contract-Based REST API"). Acumatica publishes no OpenAPI document at a stable public URL: every instance generates its own, so the `schema` tool fetches it live at `/entity/<Endpoint>/<Version>/swagger.json`. The default endpoint is `Default/24.200.001`; every tool accepts `endpoint` to use another version the instance serves (see `endpoints`). Wrapped values (`{"value": ...}`) are Acumatica's own format and are passed through unchanged.

**Auth:** user name and password of an Acumatica user with API access, plus the instance URL (https) and, for multi-tenant instances, the tenant name. Each tool call signs in with `POST /entity/auth/login`, runs and signs out with `POST /entity/auth/logout`, so licensed API sessions are not left open. Use a dedicated integration user with only the roles you need. Acumatica's OAuth 2.0 flows require a Connected Application and per-instance endpoints (`https://<instance>/identity/connect/...`) that the framework cannot declare statically, so OAuth is not offered.
**Gaps:** the provider declares `hosts: ["*.acumatica.com"]`, so the password is an opaque handle that Executor substitutes only on requests to Acumatica cloud hosts, and the instance URL is rejected unless it is `https://<name>.acumatica.com`. `*.` covers one subdomain level only, so on-premises instances and custom domains are not supported. Only the common entities have named tools; others are reachable through `entity.*`. Pagination is `top`/`skip`. File attachments and the Contract-Based API's batch operations are not covered. Mutations require approval. The tools were typechecked and deployed but not called against a live instance; in particular the tenant-scoped OData inquiry path `/odata/<tenant>/<name>` (used when a tenant is set) is a documented Acumatica form but is untested. Logout is deliberately not tied to the call's abort signal so the licensed session is still released on cancel.
