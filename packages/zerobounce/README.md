# ZeroBounce

Email validation and deliverability through ZeroBounce: real-time single validation, batch validation (up to 200 addresses), bulk validation files, credit balance, API usage, activity data, the email finder (`guessFormat`), Domain Search (single and bulk files) and bulk A.I. Scoring files.

**Interface:** custom tools written with `fetch` against `https://api.zerobounce.net/v2` (plus the `api-us` and `api-eu` hosts) and `https://bulkapi.zerobounce.net`. ZeroBounce publishes no OpenAPI document or GraphQL API. It does publish an official MCP server, [zerobounce/zerobounce-mcp](https://github.com/zerobounce/zerobounce-mcp) (npm `@zerobounce/mcp`, docs at https://www.zerobounce.net/docs/api-integrations/zerobounce-mcp-server), with 15 tools. It is stdio-only (it reads `ZEROBOUNCE_API_KEY` and runs as a local process), so it cannot be mounted as a remote MCP server and this package uses hand-written tools. Endpoints and parameters come from the vendor docs (https://www.zerobounce.net/docs/email-validation-api-quickstart, the Email Finder, Activity Data, Bulk Domain Search and A.I. Scoring pages); the official MCP source was used only to learn which operations exist.

Tools: `getCredits`, `getApiUsage`, `validate`, `validateBatch`, `activity`, `guessFormat`, `domainSearch`, `files.{send,status,get,delete}` (bulk validation), `domainSearchFiles.{send,status,get,delete}` (bulk Domain Search, `bulkapi.zerobounce.net/domain-search`) and `scoringFiles.{send,status,get,delete}` (bulk A.I. Scoring, `/v2/scoring/*`). `domainSearch` calls `guessformat` without a person's name, which is how the official MCP implements its `domain_search` tool.

**Approvals:** every call that is billed or changes state requires approval: `validate`, `validateBatch`, `activity`, `guessFormat`, `domainSearch` and every `send` and `delete` tool. Single `validate` is gated too: each call spends a credit (except unknown results), so a loop of lookups should not run unattended. Read-only tools (`getCredits`, `getApiUsage`, `status`, `get`) are not gated. Costs stated by the vendor: validation one credit per address (never for unknown results), `guessformat` 20 credits or one subscription query per successful search, bulk Domain Search 20 credits or one query per valid format, A.I. Scoring one credit per email. The vendor pages for `getcredits` and Activity Data do not state a cost.

**Regions:** the real-time tools (`getCredits`, `getApiUsage`, `validate`, `validateBatch`, `activity`, `guessFormat`, `domainSearch`) take an optional `region` of `global` (default), `us` or `eu`, selecting `api`, `api-us` or `api-eu`. Using the US host means your data is processed on US servers. All three hosts are declared. The vendor documents bulk file endpoints only on `bulkapi.zerobounce.net`, so they have no region option.

**Auth:** API key only (ZeroBounce has no OAuth). Copy it from your ZeroBounce dashboard under API (https://www.zerobounce.net/members/apikeys). It is sent as the `api_key` parameter, as the vendor API requires. The health check calls `getcredits`; an invalid key returns `Credits: -1` and is rejected.

**Known gaps:** The official MCP's `bulk_ai_scoring_*` and `domain_search` operations are covered, as are its other tools. Not exposed: single-email real-time A.I. Scoring, bulk Email Finder files, List Evaluator, Inbox Placement and Warmup (their request details were not confirmed against the vendor docs). Bulk file upload takes the file as text content.
