# N-able N-central

Covers the N-central REST API: service organizations, customers, sites and organization units, devices (details, assets, lifecycle info, service monitor status), active issues, custom properties (organization and device), scheduled tasks and task status, maintenance windows, device filters, registration tokens, users, user roles, access groups, job statuses and PSA integration endpoints. 69 tools, 17 of them mutations (each requiring approval).

Interface: OpenAPI 3.0, N-able's official API-Service definition. N-able publishes no single document at a stable URL: every N-central server (2023.9 and later) generates its own, with Swagger UI at `/api-explorer`, and the developer portal (https://developer.n-able.com/n-central/reference) embeds one OpenAPI fragment per operation. `openapi.json` is those fragments merged unchanged, minus `authenticate` and `refresh`, which the package performs itself. The document's server is the placeholder `https://{custom-server}/`, so each account's own server is used as the base URL and credentials are only ever sent to that origin.

Auth: one method, a User-API token. Create an API-only user in N-central (https://developer.n-able.com/n-central/docs/create-an-api-only-user) with MFA disabled and the roles and access groups it needs, then in Administration > User Management > Users > the user > API Access choose Generate JSON Web Token. When connecting, enter the server hostname (for example `ncentral.example.com`) and the token. The package exchanges it at `https://<server>/api/auth/authenticate` for a one-hour access token and renews it as it expires. This is done in code rather than with the framework's `oauth2` method because N-central uses no OAuth: the token endpoint is on the customer's own server.

Known gaps: the legacy SOAP API is not covered. Many endpoints are marked preview by N-able, and the set available depends on the N-central version of the server; the bundled document reflects the developer portal at the time of writing (patch reports, added in 2025.4, are not included). The provider declares no static `hosts` because servers have arbitrary hostnames. The icon is the N-able mark taken from the vendor's official logo SVG (https://www.n-able.com), with the wordmark removed. The tools were typechecked and deployed but not called against a live server.
