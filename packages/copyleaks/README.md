# Copyleaks

Plagiarism detection, AI text and AI image/video detection, grammar checking and text moderation with Copyleaks. 21 tools: credit balances and usage history, AI text detection, text moderation, grammar corrections, async AI image and video detection, URL/file/OCR scan submission, start, delete, webhook resend and export, and the reference lists of supported languages and file types.

**Interface:** hand-written tools over Copyleaks' REST API (`https://api.copyleaks.com`), written from the docs at https://docs.copyleaks.com/reference/overview. Copyleaks publishes no OpenAPI document, so these are written from the docs. Copyleaks also publishes an official remote MCP server (`https://extensions.copyleaks.com/mcp`, Streamable HTTP, https://docs.copyleaks.com/mcp/overview), mounted under `mcp` for OAuth accounts; the hand-written tools are under `rest` for email and API key accounts. Mutations (and non-read-only MCP tools) ask for approval.

**Auth:** two methods. `oauth` connects to the MCP server (OAuth 2.1 with PKCE and dynamic client registration, discovered from the server's RFC 9728 metadata; scopes `scans:read scans:run profiles:read profiles:write account:read offline_access`); the MCP server needs an account with a paid balance. `apiKey` powers the REST tools: create the key in the Copyleaks dashboard (https://api.copyleaks.com/dashboard, API Access) and enter your account email plus the key. The app logs in at `https://id.copyleaks.com/v3/account/login/api` to get a 48-hour bearer token, lazily on the first call of each tool-router build and on each health check. Copyleaks limits login to 12 requests per account per 15 minutes (then blocks for 5 minutes with 429), so avoid re-checking the account in a tight loop.

**Gaps:** the synchronous image endpoints (AI image check, image plagiarism check) take multipart uploads and are not exposed; use the async AI image tool with an image URL. Scan results for submitted scans arrive by webhook to your own server, so the REST tools cannot read them back; the MCP tools (OAuth account) can read results, history and profiles. The framework's string schema has no maximum length, so limits (scan id 3-36 characters, text 25000 or 100000 characters) are in tool descriptions and enforced by the API. Complex bodies (scan `properties`, export configuration, async image/video requests) are passed through as JSON objects as documented by Copyleaks. Use `sandbox: true` to avoid spending credits while testing.
