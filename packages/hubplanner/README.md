# Hub Planner

Resource management and timesheets in Hub Planner (now branded Resource Flow, by Milient): projects, resources, bookings, time entries, vacations, public holidays, events, milestones, clients, groups, project and resource tags, billing rates, booking and cost categories, unassigned work, custom field templates and webhook subscriptions.

**Interface:** hand-written tools over the official REST API (`https://api.hubplanner.com/v1`), documented at https://github.com/hubplanner/API and https://api-docs.hubplanner.com/. Hub Planner publishes no OpenAPI document (the docs are Markdown plus a Postman collection) and no MCP server, so about 139 tools wrap every documented section. Each tool takes path ids, `query` for URL parameters (`page` from 0, `limit` up to 1000, `sort`) and, for writes, a JSON `body` that follows the API reference. Search tools post a MongoDB-style filter as `body`. Project and resource updates are `PATCH` calls whose body is an array of objects each carrying `_id`. All writes require approval.

**Auth:** API key. An account administrator enables API access and generates a key under Settings, API in Hub Planner (https://github.com/hubplanner/API#authentication). The key is sent as the raw `Authorization` header value, without a `Bearer` prefix, to `api.hubplanner.com`. Hub Planner offers no OAuth for the public API. The key type (Read Only or Read & Write) is chosen when the key is created; write tools fail with a read-only key. The health check lists one project, so it validates the key.

**Known gaps:** the API allows 6000 calls a day and bursts of 50 per 5 seconds. The Vacation extension must be enabled for the vacation tools and the Project Managers extension for `projects.setManagers`. Unassigned work needs its extension enabled, and resource requests and subgroups need extensions as well. Booking cursor pagination is available through `query.cursor` on `bookings.list`. The deprecated per-resource calendar endpoints are not wrapped separately; send calendars in the resource body.
