# MiniMax

Covers the MiniMax API Platform (https://platform.minimax.io): text generation (OpenAI-compatible Chat Completions and Responses, Anthropic-compatible Messages, legacy chat completion V2), synchronous and asynchronous text-to-speech, speech-to-text, voice cloning, voice design and voice management, image generation, music generation, video generation (v1 and V2/H3, including context IR and regeneration), and file management.

Interface: OpenAPI, generated live from the official documents MiniMax serves from its docs site under https://platform.minimax.io/docs/ (the combined `api-reference/openapi.json`, plus the V2 video, Chat Completions, Messages, Responses, speech-to-text and v1 video documents). Each is mounted under its own key (`platform`, `video`, `videoV1`, `chat`, `messages`, `responses`, `transcription`) in one router, about 31 tools; every mutation requires approval. MiniMax publishes no single complete spec, so a few small patches in `openapi.ts` are needed: the `text/event-stream` response is removed from the chat operations (the tools return the non-streaming response), and the `AudioSetting` schema that the combined document references but does not define is added from the music generation page.

Auth: API key only; MiniMax has no user-created OAuth apps. Create a key under Account Management > API Keys in the MiniMax platform (https://platform.minimax.io/user-center/basic-information/interface-key). It is sent as a bearer token to api.minimax.io. Subscription keys from M Plan work the same way.

Group ID: the current api.minimax.io documents declare no GroupId for any operation except the `/v1/files/*` endpoints (a required `GroupId` query parameter, exposed as a normal tool input) and the async TTS status query (`group_id` in the body); everything else authenticates with the bearer key alone. The legacy/China-oriented endpoint (host api.minimaxi.chat, with a `group-id` header and `GroupId` query on every call) is not configured here. The health check is the documented read-only `POST /v1/get_voice` with `voice_type: system_voice`.

Tool count: about 31 tools are the total across the seven mounted documents; the `platform` document alone (the default `options` that scripts/check.sh compiles) yields 17 tools, 13 of them mutations, plus one skipped operation (`missing_component`: `POST /v1/video_template_generation`, whose request and response schemas are dangling references in MiniMax's document).

Known gaps: only the international endpoint (api.minimax.io) is configured; accounts on the mainland China platform (api.minimaxi.com) are not supported. `POST /v1/video_template_generation` is skipped because the combined document omits its request schema, and so are lyrics generation and music cover preprocess, which MiniMax does not publish as downloadable documents. Websocket text-to-speech, streaming output and the web-search MCP are not exposed.
