# Abstract

Abstract API's product suite: Email Reputation, Phone Intelligence, IP Intelligence, IP Geolocation, Company Enrichment, IBAN Validation, VAT Validation (validate, calculate, categories), Exchange Rates (live, convert, historical), Public Holidays, Timezones (current time, convert), Web Scraping and Image Processing.

**Interface:** hand-written tools over Abstract's official REST APIs, documented at https://docs.abstractapi.com (index: https://docs.abstractapi.com/llms.txt). Abstract publishes no OpenAPI document covering these products and no remote MCP server. Each product lives on its own host (for example `emailreputation.abstractapi.com`, `vat.abstractapi.com`, `exchange-rates.abstractapi.com`) and is a simple GET with an `api_key` query parameter (Email Reputation, Phone Intelligence and IP Intelligence also accept a Bearer header). Every host, path and parameter name was confirmed against the official per-endpoint pages (`https://docs.abstractapi.com/api/<product>/<endpoint>.md`): exchange-rates `/v1/live|convert|historical` (`base`, `target`, `date`, `base_amount`), timezone `/v1/current_time|convert_time` (`location`, `base_location`, `target_location`, `base_datetime`), vat `/v1/validate|calculate|categories` (`vat_number`, `amount`, `country_code`, `is_vat_incl`, `vat_category`), images `POST /v1/url/` with a JSON body (`url`, `lossy`, `quality`, `resize` strategies exact, portrait, landscape, auto, fit, crop, fill). The images docs show `/v1/url` but the server answers it with a 301 to `/v1/url/`, which would turn the POST into a GET, so the trailing slash is used.

**Auth:** API key only; Abstract has no OAuth. Abstract issues a separate key for every product, so add one account per product. Each account has two fields: `product` (one of `email-reputation`, `phone-intelligence`, `ip-intelligence`, `ip-geolocation`, `company-enrichment`, `iban-validation`, `vat-validation`, `exchange-rates`, `holidays`, `timezones`, `scrape`, `images`) and `token` (that product's key). An account only exposes the tools of its own product. Create keys from each product's page in the Abstract dashboard at https://app.abstractapi.com. The key goes to the product's host only: as an `Authorization: Bearer` header for Email Reputation, Phone Intelligence and IP Intelligence (keeps it out of URLs and logs), and as the `api_key` query parameter (or JSON body field for Images) for the other products, where Bearer is not documented. Errors from the JSON decoder carry only the status, never the request URL.

**Notes:** documented exception to the health-check guideline: the health check only validates the `product` name and makes no network call, because Abstract has no free account endpoint and every call spends a plan credit. A wrong or revoked key is only detected on the first tool call (401). Replace it with a real call if the credit cost is accepted. All tools are reads except `images.process`, which POSTs and requires approval. Every call consumes plan credits; free plans are limited to 1 request per second.

**Known gaps:** the Avatars and Website Screenshot APIs return binary images and are not exposed. Image upload by file POST is not exposed (URL mode only).
