# TikTok Ads

TikTok Ads through the TikTok API for Business (Marketing API v1.3): advertiser accounts, campaigns, ad groups, ads, reports (synchronous and asynchronous), creative library, custom audiences, pixels, catalogs, Business Center assets and members, Smart+, GMV Max, comments, automated rules and targeting tools. 202 typed tools from the official specs plus 29 hand-written ones; reads run freely and every create, update, status change and delete asks for approval.

**Interface:** the generated tools come from TikTok's own OpenAPI 3.0 operation files, the 202 files in `yml_files/` of https://github.com/tiktok/tiktok-business-api-sdk, pinned at commit `f809c396520df2d7b201a9ccc5378d822b728ed3`. `generate-openapi.py` merges them into `document.json` (it drops the per-operation `Access-Token` query parameter, which is sent as a header instead, and the `x-open-*` extensions, and turns four dangling `./openapi.yaml#/definitions` references into open objects). The SDK's 237 v1.3 operations are not all in `yml_files/`: core operations such as campaigns, ad groups, ads, file uploads, identities and a few tool lookups exist only in the SDK's JavaScript sources, so those are hand-written (`campaigns`, `adGroups`, `ads`, `creatives`, `targeting`, `account`) with paths checked against the SDK; their bodies and parameters are untyped `params`/`body` objects (arrays and objects in `params` are JSON-encoded for you). `api.get` and `api.post` call any remaining path, such as `/ad/aco/get/`. TikTok answers failures with HTTP 200 and a non-zero `code`; the hand-written tools turn that into an error. There is no official MCP server or GraphQL API. Docs: https://business-api.tiktok.com/portal/docs.

**Auth:** access token, sent in the `Access-Token` header. Create a developer app at https://business-api.tiktok.com/portal/apps, have an advertiser authorize it, and exchange the auth code for a token (`POST /oauth2/access_token/` with `app_id`, `secret`, `auth_code`). Paste the token into the connect page. The advertiser token lifetime is not confirmed: TikTok's SDK documents a token response with `access_token` and `refresh_token`, but its expiry wording covers creator tokens. If the token expires or is revoked, calls fail with a TikTok error code; generate a new token and reconnect. In-app OAuth is not offered because the framework reserves `client_id`, TikTok's authorize URL needs `app_id`, and the token exchange sends `app_id`, `secret` and `auth_code` in a JSON body.

**Health check:** `GET /bc/get/?page_size=1`. A token that cannot list Business Centers fails the check even if other calls would work.

**Known gaps:** multipart binary uploads of images and videos (use the URL upload tools), the app-level OAuth endpoints that need the app secret, and the SDK operations without a typed tool (reachable through `api`). Some endpoints need an approved app scope or a Business Center role; TikTok returns a permission error otherwise. Nothing was exercised against a live account.
