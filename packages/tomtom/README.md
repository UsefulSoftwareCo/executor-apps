# TomTom

Location APIs from TomTom: geocoding, reverse geocoding, fuzzy, POI, category, geometry and along-route search (Search API), route calculation and reachable range (Routing API), and raster/vector map tiles, static images, copyrights, WMS and WMTS (Maps API). 33 tools in total, mounted under `search`, `routing` and `maps`.

Interface: OpenAPI plus the official remote MCP server. The three OpenAPI specs come from the APIs.guru conversion of TomTom's published API definitions (`https://api.apis.guru/v2/specs/tomtom.com/{maps,routing,search}/1.0.0/openapi.json`), which is community-maintained rather than hosted by TomTom. POST operations that only compute a result (route calculation, geometry filters) run without an approval prompt. The official TomTom Maps MCP server (`https://mcp.tomtom.com/maps`, public preview) is mounted under `mcp`; it adds the traffic flow and incident tools the OpenAPI set lacks, plus multi-stop optimization and static maps. MCP tools prompt for approval unless they declare `readOnlyHint`.

Auth: API key. Create one at https://my.tomtom.com (or the developer portal, https://developer.tomtom.com) and enable the MCP Server product (or tick "All") plus Map Display, Routing, Search, Geocoding, Reverse Geocoding and Traffic. The key is sent as the `key` query parameter to `api.tomtom.com` and as the `tomtom-api-key` header to `mcp.tomtom.com`, per TomTom's quick-setup doc. The server also advertises OAuth metadata, but the documented method is the API key, so that is the only method offered. The optional `tomtom-maps-backend` header is not set (server default `tomtom-maps`). The health check issues a one-result geocode request, checks its `summary.numResults`, then connects to the MCP server; it consumes one billable request. The header was not exercised with a live key here (no vendor calls with credentials during authoring).

Traffic Analytics MCP: evaluated and excluded. TomTom's Traffic Analytics MCP Server (https://github.com/tomtom-international/tomtom-traffic-analytics-mcp) is a locally run open-source server with no hosted endpoint, so Executor cannot mount it; most of its tools also need a MOVE Portal account and key. Its live traffic flow and incident tools overlap the hosted Maps MCP.

Known gaps: Geofencing and other TomTom APIs have no spec in the APIs.guru set and are not covered. `scripts/tools.ts` compiles only the exported `options` (the Search spec, 19 tools), so `scripts/check.sh` does not compile the maps and routing specs.
