# Google Slides

Read, create and edit Google Slides presentations: fetch a deck as Slides JSON or a text outline, get pages and PNG thumbnails, create presentations, add/duplicate/delete/reorder slides, insert, delete, replace and style text, create shapes, images and tables, move elements, set speaker notes, plus a raw `batchUpdate` escape hatch. 19 tools.

**Interface.** Hand-written tools over the official Google Slides REST API (`https://slides.googleapis.com/v1/presentations`, [reference](https://developers.google.com/workspace/slides/api/reference/rest)). Google publishes only a Discovery document (no OpenAPI), and the API has few methods (`get`, `create`, `batchUpdate`, `pages.get`, `pages.getThumbnail`), so a converted spec would yield five tools; the hand-written tools wrap the common `batchUpdate` requests. An official Google remote MCP server for Slides does exist (`https://slidesmcp.googleapis.com/mcp/v1`, OAuth via accounts.google.com) but exposes only 4 tools (`read_presentation`, `read_slide_page`, `read_slide_page_thumbnail`, `update_presentation`), with no presentation create and no dedicated slide create/duplicate/delete/move, text, shape, image, table or speaker-note operations. Because the hand-written package offers 19 tools covering those, it was kept instead of the MCP server.

**Auth.** OAuth 2.0 only (Google has no API keys for user presentations). Create an OAuth client (type "Web application") in a Google Cloud project, enable the Google Slides API there, and paste the client ID and secret on the connect page. Add Executor's redirect URI shown on that page to the client's authorized redirect URIs. Scopes: `https://www.googleapis.com/auth/presentations` plus `openid email profile` (used for the account health check). Discovery uses `https://accounts.google.com` with `access_type=offline` and `prompt=consent` so a refresh token is issued. The `presentations` scope is a sensitive scope: Google requires OAuth app verification before users outside your test users can grant it.

**Known gaps.** No Drive operations (listing, sharing, deleting, exporting; use a Google Drive package). Creating Sheets-linked charts and other rarely used requests are available only through `batchUpdate`. Mutating tools always require approval. Not verified against a live account.
