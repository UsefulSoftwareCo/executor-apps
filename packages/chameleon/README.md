# Chameleon

Chameleon is a product adoption platform (tours, microsurveys, launchers, tooltips, embeddables). This package covers the Chameleon REST API: user profile and company search, lookup, upsert and deletion; event tracking and event names; custom properties; segments; tours, microsurveys, launchers, tooltips and embeddables (list, get, publish, tag and environment updates); tour interactions and microsurvey responses; deliveries (trigger an experience for one user); tags; environments and domains; themes; rate limit and alert groups; data import status; change history; and outgoing webhook subscriptions. 68 tools.

**Interface:** hand-written tools over `https://api.chameleon.io` (API version v3). Chameleon publishes its reference at https://developers.chameleon.io but no OpenAPI document, so each operation was written from that reference. Mutations (upserts, event tracking, deliveries, updates, deletes, webhook changes) require approval; searches and counts are POST requests but read-only and need none. `properties` inputs on upsert and event tools are merged into the request body as custom attributes. Cursor pagination uses `limit`, `before` and `after`.

**Auth:** account secret, sent in the `X-Account-Secret` header. Create it at https://app.chameleon.io/settings/tokens; tokens are account-specific and shown only once. Chameleon has no OAuth for this API.

**Gaps:** creating CSV data imports, creating or editing domains and environments, steps, elements, buttons, demos and the HelpBar search API are not included; neither are the bulk (batch) upsert endpoints. Experience update tools accept only the documented `url_group_id`, `tag_id` and `published_at` fields. Single-delivery lookup is omitted because Chameleon documents no Show endpoint for deliveries (use the list tool filtered by model_id or profile_id). `profiles.delete` and `deleteByUid` clear/reset a profile, as documented; use `forget` for permanent erasure. The profile search body also sends `limit`, `before` and `after`, which its page does not document. Nested query objects (`expand`) are sent in bracket form (`expand[profile]=all`). Experience updates take `published_at` as an ISO time to publish or `null` to unpublish. The icon is the vector mark from Chameleon's own site (https://www.chameleon.io/img/favicons/favicon.svg), not a press-kit download.
