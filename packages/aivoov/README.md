# Aivoov

AiVOOV text-to-speech: list the voice catalogue (1,000+ voices, 150+ languages) and synthesize speech from one or more voice and text segments, with optional per-segment pitch, speaking rate and volume.

**Interface:** hand-written tools over AiVOOV's official REST API v8 (`https://aivoov.com/api/v8`), documented at https://github.com/AiVOOV/aivoov-api. AiVOOV publishes no OpenAPI document and no MCP server. Four tools: `listVoices` (`GET /voices`), `createAudio` (`POST /create`, requires approval; returns Base64 audio in `audio`), `createTranscription` (`POST /speech`, multipart upload, requires approval; the audio file is passed as Base64 in `audioBase64` with a `fileName` and `language`) and `getTranscription` (`GET /job?job_id=`, returns status, `text` and `srt`). Speech-to-text is documented in `speech-to-text-api.md` of the same repository (30 POSTs per minute, 1,000 requests per day, files up to 10 MB). AiVOOV reports many failures as HTTP 200 with `status: false` or `result: false`; every tool and the health check turn those into errors.

**Auth:** API key, sent as the `X-API-KEY` header to `aivoov.com`. Find it after logging in at https://aivoov.com under Profile, then API. The account needs character credits. AiVOOV has no OAuth.

**Notes and gaps:** the API has no account or usage endpoint, so the health check calls `/voices`, which AiVOOV caps at 20 calls per day. Every health run spends one of those calls, shared with `listVoices`, and when the quota is exhausted the vendor returns a failure that makes a valid account report unhealthy (the error message says so; it does not mean the key is invalid). No uncapped read-only endpoint exists, so the check is kept (`/create` is 75 per minute, 5,000 requests per day overall). The audio format is not documented. `pitchRate` (-50 to 50), `speakingRate` (20 to 200) and `volume` (-40 to 40) are validated as integers in range before the request. A setting must be given on every segment or on none, because the API pairs the arrays by position; the API's literal `default` value is therefore only reachable when every segment omits the field (the schema builders have no string-or-number union). The `/voices` response envelope is documented two ways (top-level array vs `{status, message, data}`), so both are accepted until checked against a live response. The icon is AiVOOV's official wordmark SVG, https://aivoov.com/assets/images/aivoov.svg (the file the homepage references; it is byte-identical to https://aivoov.com/upload/ce9bb3f4740fc900384f7997786407a2.svg), as no standalone mark is published. It stays legible at 20 px height on white and near-black (the navy letters are drawn white in the dark variant).
