# Klipfolio

Manage Klipfolio business intelligence from an agent: Klips (including schemas, annotations and share rights), dashboards (Klip instances, layout, published links), data sources and their instances (properties, refresh, pushing data), client accounts, users, groups and roles. 122 tools, grouped by area (`klips`, `dashboards`, `datasources`, `datasourceInstances`, `clients`, `users`, `groups`, `roles`, `profile`).

**Interface:** hand-written tools over Klipfolio's official REST API at `https://app.klipfolio.com/api/1.0`. Klipfolio publishes no OpenAPI/Swagger document (its docs at https://apidocs.klipfolio.com/ are per-resource pages, indexed at https://apidocs.klipfolio.com/llms.txt) and no MCP server. `routes.ts` is a table of every endpoint in that reference (method, path, path and query parameters, description), and `index.ts` turns each row into a tool. Request bodies are passed as a `body` JSON object; fields are listed in each tool description and in the docs. Responses are returned as the API sends them (`{ data, meta }`).

**Auth:** API key only. The vendor's getting-started page (https://apidocs.klipfolio.com/reference/getting-started) says the API works with both Basic authentication and API keys; this package offers only the API key, because Basic auth needs an account username and password, which an agent should not hold. Klipfolio has no user-created OAuth apps. Create the key in Klipfolio from the My Profile page, or from Users if you are an administrator with the `user.manage` permission. It is sent in the `kf-api-key` header to `app.klipfolio.com`. The health check reads `/profile`.

**Host:** the vendor index (https://apidocs.klipfolio.com/llms.txt) names `https://api.klipfolio.com/api/1.0/`, while the per-resource pages and getting-started use `https://app.klipfolio.com/api/1.0`. Both hosts answer 401 to an unauthenticated `/profile` call. The package keeps `app.klipfolio.com` because it matches the per-resource pages.

**Notes and gaps:** every non-GET tool asks for approval. Request bodies are untyped JSON, and responses are not schema-checked. Lists page with `limit` (max 100) and `offset`. Rate limits: 5 requests per second, plus a daily request cap that depends on the plan and resets at midnight ET; exceeding either returns 429. The docs show a "Create new role" example at `POST /roles/{id}`, which is not a real route (the heading says `POST /roles`), so the package has no create-role tool; roles can be updated and deleted only. Icon: the K mark with the red corner from Klipfolio's official logo SVG (https://www.klipfolio.com/logos/klipfolio-logo.svg), recomposed without the wordmark.
