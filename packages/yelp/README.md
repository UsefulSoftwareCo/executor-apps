# Yelp

Search Yelp businesses, read reviews and categories, find events and ask Yelp AI about local places: 14 tools across businesses, categories, events, transactions and Yelp AI.

**Interface:** hand-written tools over the Yelp Fusion REST API (`https://api.yelp.com/v3`) and Yelp AI (`https://api.yelp.com/ai/chat/v2`), written from the official reference at https://docs.developer.yelp.com. Yelp publishes no downloadable OpenAPI document. Its GraphQL API (`https://api.yelp.com/v3/graphql`, official, same Bearer key) is in beta and covers less than the documented REST API, which is Yelp's primary interface, so REST was used. Yelp's MCP server (`https://mcp-openai.yelp.com/mcp/`) was probed and returned an HTML 403 Forbidden page (also with a browser User-Agent) with no auth challenge or protected-resource metadata; the probe is inconclusive rather than a confirmed block, and it was not pursued because the REST API is documented and covers the same ground. All tools are read-only, so none require approval; Yelp AI chat is a POST but changes no data, so it is exposed as a query. Input limits the framework schema cannot express (match country `[A-Z]{2}`, state max 3, postalCode max 12, limit 1-10, matchThreshold none/default/strict, AI query max 1000, delivery term max 300) are checked in code.

**Auth:** API key only. Yelp does not offer OAuth to third-party users. Create an app at https://www.yelp.com/developers/v3/manage_app and paste its API key; it is sent as `Authorization: Bearer <key>`.

**Known gaps:** reviews require an Enhanced or Premium Yelp plan and return at most three excerpts; review highlights require the Premium plan; some search attributes are Premium-only. Delivery search does not expose limit/offset. Partner-tier APIs (leads, advertising, reservations, reporting) are not covered. Events and food-delivery endpoints are documented by Yelp but may be limited for some keys. Health checks make one category lookup, which counts toward the daily quota.
