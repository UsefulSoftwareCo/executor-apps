# Crawlbase

Crawlbase fetches web pages through its proxy and anti-bot infrastructure. This package covers the Crawling API (HTML, JSON or Markdown output, JavaScript rendering, screenshots, POST/PUT, built-in scrapers), Cloud Storage (retrieve, list, count and delete stored pages), the Account usage endpoint, and Enterprise Crawler queue management (create, update, pause, purge, push URLs). 21 tools.

Interface: hand-written tools over the documented REST endpoints at https://crawlbase.com/docs/ (Crawling API, Storage API, Account API, Crawler). Crawlbase publishes no OpenAPI document, but it does run an official hosted MCP server (https://mcp.crawlbase.com/mcp, streamable HTTP with `Authorization: Bearer <token>`; docs at https://crawlbase.com/docs/ai-mcp) exposing 9 tools (crawl, crawl_markdown, crawl_screenshot, storage_get, storage_bulk_get, storage_list, storage_count, storage_delete, storage_bulk_delete). This package is a superset: all of those are covered, plus Enterprise Crawler queue management and Account usage that the MCP server lacks, for 21 operations. Each tool takes a `params` object whose fields are the documented query or body parameters; the tool descriptions list them.

Auth: API tokens only (Crawlbase has no OAuth). Copy your Normal token and, optionally, your JavaScript token from the Crawlbase console (https://crawlbase.com/console) after signing up; the Reset token button regenerates them. Calls use the Normal token; pass `token_type: "javascript"` to `crawl.fetch` (GET only; POST and PUT reject it) to use the JavaScript token. Both go to `api.crawlbase.com` as the `token` query parameter (or in the path for crawler management), as Crawlbase requires.

Approvals: every tool that changes state (POST/PUT through the crawler, pushing to a queue, deleting storage, managing crawlers) asks for approval. `storage.bulkGet` is also gated because `auto_delete` permanently removes pages. `crawl.fetch` is treated as read-only but still bills the account per successful request, and with `store=true` writes to Cloud Storage.

Known gaps: the legacy Scraper, Leads, Screenshots and Proxy APIs and the Smart AI Proxy are not exposed. Bulk storage bodies are returned base64 gzip as Crawlbase sends them. The account endpoint is limited to one call per 5 minutes. Response shapes were taken from the docs, not from live calls.
