# JobDiva

Staffing and recruiting with JobDiva: candidates, jobs, companies, contacts, activities, divisions, financial records, placements, timesheets and BI reports (438 Version 2 operations plus 294 Version 1 operations).

**Interface:** OpenAPI. JobDiva publishes Swagger 2.0 documents without authentication at https://api.jobdiva.com/swagger-resources. Both are mounted and compiled live: API Version 2 (current, tools under `v2.*`, 438 operations, 143 mutations) at https://api.jobdiva.com/swagger?group=Version%202, and API Version 1 (tools under `v1.*`, 294 tools, 41 mutations) at https://api.jobdiva.com/swagger?group=Version%201. Version 1 is mounted because about 175 of its 318 operations (mostly `/bi` reports) have no Version 2 counterpart; 143 do overlap, so prefer `v2.*` when both exist. 24 Version 1 operations are skipped because the vendor document declares an invalid parameter location. Mutations (every non-GET operation) require approval. Several POST operations are searches; they also require approval.

**Auth:** API user (client ID, username, password). The account signs in with `GET /apiv2/authenticate?clientid=&username=&password=` (Version 1 uses `/api/authenticate`; each version gets its own cached token, URL-encoded credentials), caches the returned token for an hour and sends it as `Authorization: Bearer <token>`; a 401 forces a fresh sign-in. The client ID can only be issued by JobDiva support (support@jobdiva.com). Create the API user in JobDiva under Settings > My Team > Add User with "Only allow access to JobDiva API Calls" enabled; it is not a normal login. The vendor's spec declares an `Authorization` header scheme, so the generated operations are bound to the password field only to compile; the app replaces that header with the sign-in token on every request.

**Gaps:** 24 Version 1 operations are not available (see above). JobDiva has no OAuth and no official MCP server. Webhooks are not covered. Tokens, `GET /apiv2/authenticate` and the API user's data access depend on the permissions JobDiva grants that user.
